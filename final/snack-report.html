One visitor came back 21 times in one day: password123 → wer → n → f → (empty) → a. At some point they realized the door had no lock. They tried the empty string anyway. Respect the commitment.

// The one thing you can do right now
Turn off SSH password authentication. Use a key instead. A key is a digital lock that no wordlist can guess. Run ssh-keygen, add the public key to your server, set PasswordAuthentication no in your SSH config. That's it. Every session in this 40-page report worked because the server accepted passwords. Remove that and 99% of this goes away.
